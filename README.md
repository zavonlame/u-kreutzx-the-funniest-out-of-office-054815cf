## Entry

> Out of office until Monday. I'm ignoring you in person this week instead of by email.

## How it runs

`main.ts` embeds the reply as a string literal, reads no files, and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (Node 22 standard library only).
